## FAQ

### What is XCutors?

XCutors is a curated Windows bundle that packages multiple popular Roblox script executors together with a universal loader, so you can choose and manage them from a single interface.

### Which executors are included?

The collection includes Volt, Synapse Z, Potassium, Wave, and xcutorsLoader (the universal loader that ties them all together).

### Is this free to use?

Yes. XCutors itself is free. Individual executors bundled within may have their own licensing — some are free and some may require a purchased license key.

### What operating systems are supported?

XCutors is built exclusively for Windows (10 and 11). Linux and macOS are not supported at this time.

### How do I update the executors?

Open xcutorsLoader and click 'Check for Updates.' It will detect newer versions of each bundled executor and offer a one-click update.

### Why does my anticomponent flag the loader?

Some anticomponent engines may flag script loaders as potentially unwanted programs. You may need to whitelist the XCutors folder in your anticomponent software. Always download from this official repository.

### Can I add my own scripts to the script hub?

Yes. Place any .lua or .txt script files into the 'Scripts' folder inside the XCutors directory. They will appear in the script hub on next launch.

### The executor fails to attach — what should I do?

Make sure Roblox is fully loaded in a game, run the executor as Administrator, and ensure your anticomponent is not blocking the process. Restart both Roblox and the executor if the issue persists.

### Does this work on all Roblox games?

Executors work with most games, but individual games may implement protections that prevent or limit script execution. Success varies by game.
